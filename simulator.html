محاكي القطع 🧪

حرّكي كل قطعة بإيدك وشوفي شو بيصير، قبل ما نفتح Tinkercad · رجوع للعرض

اللمبة والمقاومة

شغّلي الدائرة. وبعدين جرّبي تشيلي المقاومة وشوفي شو بيصير.

التحكم

الدائرة طافية. اضغطي «تشغيل الدائرة».

فكّري: ليش اللمبة احترقت لما شلنا المقاومة؟

زر الضغط والمفتاح

اضغطي على الزر وكمّلي ضاغطة، وبعدين اتركيه. وجرّبي المفتاح. شو الفرق؟

التحكم

جرّبي الاثنين.

فكّري: جرس البيت زي أي وحدة فيهم؟ ومفتاح ضو الغرفة؟

المقاومة المتغيرة

لفّي الزر شوي شوي، وراقبي ضو اللمبة والرقم.

التحكم

القيمة: 0

القيمة صفر: اللمبة طافية.

فكّري: شو الفرق بينها وبين الزر؟ كم درجة بيعطيكِ الزر؟

حساس المسافة

قرّبي السيارة من الحساس وبعّديها. الحساس بيقيس المسافة بصدى الصوت.

التحكم

المسافة: 0 سم

فكّري: وين شفتي حساس زي هاد بحياتك؟

محرك السيرفو

اختاري الزاوية، والسيرفو بيروح عليها وبيوقف.

التحكم

الزاوية: 0°

بالكود منكتب: s1.write(90); فبيروح لـ 90 وبيوقف هناك.

فكّري: قديش لازم تكون الزاوية عشان ذراع البوابة يصير واقف لفوق؟

البوابة الذكية: كل القطع مع بعض

قرّبي السيارة من البوابة. الحساس بيشوفها ← الأردوينو بيقرر ← السيرفو بيفتح، واللمبة بتتغير.

التحكم

المسافة: 0 سم

if (distance < 30) { gate.write(90); green ON; }
else { gate.write(0); red ON; }

فكّري: مين العيون؟ مين الدماغ؟ مين الإيدين؟
